# SDD-консультант для студентов РосНОУ
## 1. О проекте

**Название:** SDD-консультант для студентов РосНОУ.

**Направление:** Spec-Driven Development (SDD).

**Платформа:** Yandex AI Studio, Agent Atelier.

**Язык:** русский.

Цель проекта — подготовить учебного ИИ-консультанта, который помогает студентам изучать SDD, формировать спецификации, составлять тесты и анализировать ошибки.

## 2. Участники и распределение работы

Работа подготовлена индивидуально.

Основные выполненные задачи:

- Подготовка спецификации проекта.
    
- Разработка первой версии инструкции ИИ-агента.
    
- Подготовка улучшенной версии инструкции.
    
- Разработка семи тестовых сценариев.
    
- Анализ и обоснование улучшений.
    
- Подготовка документации и описание технического блокера.

## 4. Предполагаемые возможности агента

SDD-консультант должен:

- Объяснять принципы Spec-Driven Development.
    
- Превращать идеи пользователя в проверяемые спецификации.
    
- Предлагать критерии приёмки и тестовые сценарии.
    
- Проверять спорные утверждения с помощью Web Search, если он доступен.
    
- Анализировать замечания и предлагать исправления.
    
- Различать предложенные, выполненные и проверенные действия.
    

## 5. Настройки агента

Предполагаемая конфигурация первой версии:

- Платформа: Yandex AI Studio.
    
- Раздел: Agent Atelier → Текстовые агенты.
    
- Тип: текстовый агент.
    
- Язык общения: русский.
    
- Web Search: должен быть включён.
    
- Генерация изображений: отключена.
    
- Code Interpreter: отключён.
    
- Индексы, MCP-серверы и дополнительные навыки: не используются.
    

**Фактическая конфигурация:** агент не создан. Модель, настройки и номер сохранённой версии не зафиксированы.

## 6. Проверка и воспроизведение испытаний

В соответствии с заданием подготовлены семь тестовых сценариев.

Для полноценного воспроизведения проверки необходимо:

1. Создать текстового агента в Yandex AI Studio.
    
2. Установить инструкцию PROMPT-v1.
    
3. Выполнить семь независимых тестов в новых диалогах.
    
4. Сохранить ответы и оценить результаты.
    
5. Установить PROMPT-v2 и сохранить новую версию.
    
6. Повторить те же семь тестов.
    
7. Сравнить результаты и зафиксировать изменения.
    

Фактически описанные испытания пока не проведены из-за невозможности создать агента.

## 8. Известные ограничения и технический блокер

При попытке создать текстового агента в Yandex AI Studio (Agent Atelier) возникло ограничение доступа.

**Полученная ошибка:**

- Код ошибки: `403 PermissionDenied`.
    
- Операция: `authorize create agent`.
    
- Request ID: `5581fccf-0f06-407c-82b8-6258118dbdc8`.
    
- Trace ID: `00000000000000002d828dd54bc930cd`.
    

Одновременно интерфейс Yandex AI Studio отображал требование привязать платёжный аккаунт к облаку для использования сервиса.

Для активации личного платёжного аккаунта Яндекс запрашивает банковскую карту. 

**Состояние практической части:**

- Агент не создан.
    
- Модель и версия агента не выбраны.
    
- Сохранённые версии агента отсутствуют.
    
- Тестовые сценарии в AI Studio не запускались.
    
- Фактические ответы агента не получены.
    
- Telegram-интеграция не подключалась.
    

**Выполненная подготовительная работа:**

- Подготовлена спецификация проекта.
    
- Подготовлены две версии инструкции агента.
    
- Составлены семь тестовых сценариев.
    
- Подготовлено описание предполагаемого улучшения второй версии.
    
- Составлена документация проекта.
    

В соответствии с разделом 11 задания преподавателя при недоступности сервиса необходимо зафиксировать технический блокер, подготовить спецификацию, инструкцию и тесты, а результаты испытаний отметить статусом «не выполнен — технический блокер».

Таким образом, проектная документация подготовлена, однако создание и практическая проверка агента не выполнены.

**Статус:** не выполнен — технический блокер.
